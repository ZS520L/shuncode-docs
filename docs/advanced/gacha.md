# 抽卡判断

:::tip[核心]

**Arena 的 Agent 模式，每次新开对话都是随机分一个模型，一轮对话里模型不会变。** 所以每次新开对话都是一次抽卡：抽到好模型就往下干，抽到弱的就关掉重开。

下面四个办法，能在前几句话里就判断出这次抽到的是不是好牌。

:::

## 为什么 Arena 上的模型不会「降智」

Arena 是大模型排行榜，各家厂商把模型放上去是为了**比分数、做宣传**的。在这里放一个阉割版、限速版，等于自己打自己的脸，没有哪家愿意。

反过来，各家官方入口为了省成本，高峰期偷偷换小模型、砍推理长度、限上下文，这种「降智」时有传闻。**官方有可能降智，Arena 上不可能。**

所以 Arena 是目前免费入口里模型质量最有保障的一个。代价是你不能指定模型——那就学会判断。

## 办法一：看能不能识图

新开对话，先丢一张图进去，问「这图里有什么」。

- **能准确描述** → 多模态模型。多模态模型通常是各家的旗舰或次旗舰，代码能力一般也更强。
- **说看不到图 / 胡编** → 纯文本模型，或是较老的版本。不一定差，但下限更低。

这一步最省事，一句话就能筛掉一批。

## 办法二：看首次连接的行为和速度

把 ShunCode 的 MCP 链接发过去，观察模型第一步做什么：

| 表现 | 判断 |
|---|---|
| 很快连上，只做必要的初始化，然后等你说话 | **好模型**。理解了任务边界，不乱动 |
| 连上之后自作主张把目录列一遍、把文件读一堆、开始「分析项目」 | 中等。能干活，但容易多做、多花时间 |
| 连不上、反复重试、或者问你「这个链接是干什么的」 | 弱模型，或者工具调用能力差，直接换 |

只连接、不做多余动作、且很快——这三条同时满足的，基本都是好牌。

## 办法三：读 thinking 里的措辞

如果界面能看到模型的思考过程，看它用什么人称和语气：

```
I'll ...        >   We need to ...   >   Let me ...
（直接决策）        （在推理约束）        （试探、犹豫）
```

- **`I'll`** 开头：已经想清楚，直接宣布要做什么。执行力强。
- **`We need to`**：还在梳理条件和约束，稳，但会慢一点。
- **`Let me`**：试探性动作，边看边想，容易反复。

不是绝对规律，但和实际干活质量的相关性很高。连续几条思考都是 `Let me try…` 的，可以考虑重开。

## 办法四：让它画画，一眼见高下

代码能力不好直接比，但**视觉产物一眼就能看出差距**。三个经典测试：

### 鹈鹕骑自行车

这是一道经典的模型能力测试题。想快速筛，一句话就够：

> 用 SVG 画一只鹈鹕骑自行车。

想把差距拉到最大，用下面这条：

```text
请使用纯 SVG 和原生 SMIL 动画（或纯 CSS），制作一个"鹈鹕骑自行车"的完整 2D 动态页面。
```

同一条提示词，两次抽卡的产出放在一起，不用懂代码也能分出高下：

### 火柴人大战

这道题考的是**多角色的动作编排**：两个角色、一条时间线，谁出招、谁挨打、节奏怎么咬合，弱模型很难编圆。提示词同样只要一句：

```text
请使用纯 SVG 和原生 SMIL 动画（或纯 CSS），制作一个"火柴人大战"的完整 2D 动态页面。
```

好牌交出来的效果，直接嵌在下面（纯 SVG + SMIL，零 JavaScript，动的就是页面本体）：

弱牌的典型症状：两个火柴人各打各的，拳头永远够不到对方，招式之间没有攻防因果——都在动，但没有「战斗」。能把多个对象的动作编排咬合在一起，才有能力处理真实项目里互相牵连的模块。

### 用 CSS 复刻一张动漫图

丢一张动漫角色图，一句话：

> 用纯 HTML + CSS 复刻这张图，不许用图片，不许用 SVG。

这道题同时考识图（办法一）、空间理解、代码组织三项，而且**没法蒙**：五官在哪、胳膊怎么接、头发怎么分层，全得自己算。

差距不用解释：有的几乎就是原图平替，人物像是描下来的；有的还在纠结五官该放哪、胳膊该怎么接；有的只能堆出几个色块。**能力高低，一眼就「看」出来了。** 你抽到的模型画出来是哪一档，心里立刻有数。

:::info[这几道题的用法]

不用真的等它画完。看它**前 30 秒的思路**——是先规划结构还是直接开写、有没有分层、有没有考虑比例——大致就能定级。画完再看一眼结果确认即可。

:::

## 判断完怎么办

- **好牌**：直接开工。同一轮对话里模型不会变，把这一轮用足。
- **弱牌**：别犹豫，关掉重开。Arena 免费、无限次，重开的成本是零。
- 判断多了会形成手感：往往前两句话就知道该不该继续。

:::tip[配合 Bridge]

用 [Bridge](../bridge/overview.md) 接 Arena 时，这套判断照样适用。抽到好牌之后，让它直接在你本机项目上干活，一轮对话能顶别人一天。

:::
