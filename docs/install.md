# 下载安装

Chat 模式和 Bridge 模式用的是同一份软件。先装好，再选一条路径往下看。

## 安装

从 [GitHub Releases](https://github.com/ZS520L/shuncode) 下载当前稳定版，安装后打开任意工作区。

当前版本：0.6.9。

## 装好之后

| 你要做的事 | 下一页 |
| --- | --- |
| 在编辑器里和模型对话、改代码 | [Chat 模式](./chat/overview.md) |
| 用手机或另一台电脑的浏览器操作本机项目（工作区） | [Bridge 模式](./bridge/overview.md) |

本地 Chat 模式打开工作区即可用，但要先 [配置模型](./chat/api-key.md)。Bridge 还要登录并购买套餐，见 [Bridge 概览](./bridge/overview.md)。
